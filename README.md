## Features
- **Responsive Design**: The layout adjusts seamlessly across all screen sizes, from large desktops to small mobile screens.
- **Smooth Scroll**: Navigation links use smooth scrolling for a more fluid user experience.
- **Interactive**: Project cards and navigation links have hover effects for better interactivity.
- **GitHub Integration**: Links to my projects on GitHub for easy access to my code.

## Technologies Used
- **HTML5**: For structuring the content.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and smooth scrolling.
- **Font Awesome**: For icons in the skills section.
